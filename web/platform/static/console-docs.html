快速开始

使用 API 兼容 OpenAI 标准格式，可直接替换 base_url 使用。

import openai

client = OpenAI(
    api_key="你的 API Key",
    base_url="https://api.example.com/v1"
)

response = client.chat.completions.create(
    model="minimaxai/minimax-m3",
    messages=[{"role": "user", "content": "你好"}],
    stream=True
)
for chunk in response:
    if chunk.choices[0].delta.content:
        print(chunk.choices[0].delta.content, end="")
可在 密钥管理 页面创建和管理 API 密钥。
POST /v1/chat/completions - 对话补全

创建模型对话接口，支持流式和非流式输出。

请求参数
参数类型必填说明
modelstring是模型 ID，见 模型列表
messagesarray是消息列表，含 role 和 content
streamboolean否是否流式输出，默认 false
max_tokensint否最大生成 token 数
temperaturefloat否采样温度 0-2，默认 1
toolsarray否函数调用工具列表
请求示例
POST /v1/chat/completions
Content-Type: application/json
Authorization: Bearer sk-xxxxx

{
  "model": "minimaxai/minimax-m3",
  "messages": [
    {"role": "system", "content": "你是一个有用的助手"},
    {"role": "user", "content": "你好"}
  ],
  "stream": true,
  "max_tokens": 1024
}
响应示例（非流式）
{
  "id": "chatcmpl-xxx",
  "object": "chat.completion",
  "model": "minimaxai/minimax-m3",
  "choices": [{
    "index": 0,
    "message": {
      "role": "assistant",
      "content": "你好！有什么我可以帮助你的？"
    },
    "finish_reason": "stop"
  }],
  "usage": {
    "prompt_tokens": 20,
    "completion_tokens": 15,
    "total_tokens": 35
  }
}
GET /v1/models - 模型列表

获取所有可用模型列表。

GET /v1/models
Authorization: Bearer sk-xxxxx
无需认证也可访问，返回所有可用模型。
POST /v1/embeddings - 嵌入向量

生成文本的嵌入向量表示。

POST /v1/embeddings
Content-Type: application/json
Authorization: Bearer sk-xxxxx

{
  "model": "nvidia/nv-embed-v1",
  "input": "要生成嵌入的文本"
}
POST /v1/messages - Anthropic 协议（Claude 兼容）

兼容 Anthropic Messages API，可使用 Claude 官方 SDK 直接调用。

POST /v1/messages
Content-Type: application/json
x-api-key: sk-xxxxx

{
  "model": "deepseek-ai/deepseek-v4-pro",
  "max_tokens": 1024,
  "messages": [
    {"role": "user", "content": "你好"}
  ]
}
使用 x-api-key 头认证，兼容 Anthropic SDK 的 base_url 配置。
POST /v1/responses - OpenAI Responses API

兼容 OpenAI Responses API，支持 Codex CLI 等工具的默认协议。

POST /v1/responses
Content-Type: application/json
Authorization: Bearer sk-xxxxx

{
  "model": "deepseek-ai/deepseek-v4-pro",
  "input": "你好，介绍一下你自己"
}
POST /v1beta/models/{model}:generateContent - Gemini 协议

兼容 Google Gemini API，可使用 Gemini 官方 SDK 调用。

POST /v1beta/models/deepseek-ai/deepseek-v4-pro:generateContent
Content-Type: application/json
x-goog-api-key: sk-xxxxx

{
  "contents": [{
    "parts": [{"text": "你好"}]
  }]
}
使用 x-goog-api-key 头认证，兼容 Google Gemini SDK 的 api_endpoint 配置。
